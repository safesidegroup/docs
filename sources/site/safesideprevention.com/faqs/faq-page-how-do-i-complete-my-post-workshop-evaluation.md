# How do I complete my post-workshop evaluation?

Towards the end of the last module in the InPlace Workshop, a link to the evaluation comes on-screen prompting participants to complete it. It will look like this:

![](https://safesideprevention.com/media/images/i8jzp6t8216hz3t9l41vg672pa8y.webp)

 
 
You can also find the link at the end of your Participant Workbook, which the host provides the participants with.
